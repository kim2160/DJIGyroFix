DJI Gyro Fix v0.91 사용 방법
===========================

1. DJI_Gyro_Fix.exe를 실행합니다.
2. 제목 오른쪽의 'KOR' 또는 'ENG' 버튼으로 화면 언어를 선택합니다.
3. DJI 카메라의 원본 MP4/MOV 파일을 선택합니다.
4. 처리할 시작 시간과 종료 시간을 입력합니다.
   예: 시작 22 / 종료 24
   '+'로 구간을 추가하고 '−'로 삭제할 수 있으며 최대 10개까지 입력할 수 있습니다.
   추가된 행의 시작/종료가 모두 비어 있으면 자동으로 건너뜁니다.
5. 필요하면 '검출'을 눌러 각 구간의 이상 흔들림 위치와 강도를 확인합니다.
6. 'FIX'를 누릅니다. 입력한 모든 시작~종료 구간을 한 번에 수정합니다.

원본은 변경되지 않습니다.
같은 폴더에 '_gyro_fixed'가 붙은 수정 영상이 저장됩니다.
인터넷, AI, Gyroflow 설치가 필요하지 않습니다.

주의
----
- 저장 공간은 원본 영상 크기만큼 필요합니다.
- DJI의 djmd 자세 데이터가 포함된 카메라 원본을 사용하세요.
- 입력한 모든 시작~종료 시간 밖의 자이로 데이터는 그대로 유지합니다.
- 서로 겹치는 구간은 자동으로 하나로 합쳐서 처리합니다.
- 작업 중에는 파일 저장이 끝날 때까지 프로그램을 종료하지 마세요.
